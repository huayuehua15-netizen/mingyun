# 01 · 产品需求文档

## 1. 项目定位

一句话定位：**能自己部署的 AI 术数排盘台。**

灵感来自 TapTap 上的《天机六爻》——它证明了"术数 + 现代交互"在年轻玩家群体里有真实需求。但小游戏形态受限于移动端竖屏和平台生态，盘面展示局促、只能做单一术数、AI 解读是黑盒。本项目要做的是它的**桌面增强版 + 开源版**：

- **桌面优先**：大屏才能真正画好一张十二宫盘、一张天地盘。移动端做适配但不做主导。
- **六术并列**：不是"六爻 App 附带别的"，而是六套独立引擎，各自有专业级盘面；前三术看长期与结构，后三术专门补近期一件具体事。
- **AI 是解说员不是算命先生**：模型负责把盘面翻译成人话，而不是替代人断卦。
- **开源可自部署**：数据和出生信息留在自己机器上，模型自己选，包括完全离线的本地模型。

## 2. 目标用户

| 用户群 | 特征 | 核心诉求 | 占比预估 |
|---|---|---|---|
| 术数爱好者 | 会自己装卦、起课，用过专业排盘软件 | 排盘必须准，规则可查，能与手工结果对上 | 20% |
| 好奇尝鲜者 | 刷到过相关内容，不会断卦 | 摇一次、看一眼、听 AI 讲明白，过程要有仪式感 | 65% |
| 自部署用户 | 有服务器/NAS，在意隐私，或想做二次开发 | 一键拉起、模型可换、接口可对接 | 15% |

**关键判断**：65% 的尝鲜者是流量入口，但 20% 的爱好者决定口碑。排盘准确性是生死线，交互趣味性是增长线，二者都不能妥协——这正是文档里算法章节写得比 UI 章节细的原因。

## 3. 核心价值主张

1. **准**：排盘结果与权威万年历、专业排盘软件逐字段对得上，有可复现的测试集。
2. **讲得明白**：AI 输出不是玄学术语堆砌，而是"盘面要点 → 结论 → 应期 → actionable 建议"四段式。
3. **看得见**：每个结论都能在盘面上高亮对应爻位或宫位，点一下断语就跳到依据。
4. **拿得走**：MIT 许可，Docker 一条命令起，模型配置写在 `.env` 里。

### 4.5 明确不做（本版非目标）

- 不做真人在线命理师撮合、打赏、连麦。
- 不做"改运、消灾、化解、开光"类付费服务——这是法律与道德双重红线，详见 09 合规文档。
- 不做社区论坛、UGC 断卦内容（v1 不做，避免内容审核成本）。
- 不做小程序原生端（H5 响应式足够）。
- 不做多语言（先中文，接口层预留 i18n 字段）。

## 5. 典型用户旅程

**旅程 A：首次访问的尝鲜者（最重要的转化路径）**

进入首页 → 看到当日干支、节气、月将的"今日盘头" → 点"摇一卦" → 六次铜钱动画，每次落一枚爻 → 卦成，盘面逐爻点亮 → 输入想问的事（如"这次面试能不能成"） → AI 流式讲解，讲到"用神"时，卦盘上对应那爻同步发光 → 底部给出三条建议 + 免责声明 → 提示"注册可保存这张盘"。

全程不超过 3 分钟，不注册也能走完。

**旅程 B：爱好者的校验路径**

选择"手动录入" → 逐爻点选阴阳动静 → 生成盘面 → 立刻核对纳甲、世应、伏神、旬空 → 与自己的手工结果比对 → 若一致，信任建立，开始用 AI 做第二意见。

**旅程 C：自部署用户**

`git clone` → 复制 `.env.example` → 填模型 base_url 和 key → `docker compose up -d` → 访问 8080 → 首次启动引导设置管理员账号 → 整个站点归自己。

## 6. 成功指标

| 指标 | 目标 | 观测方式 |
|---|---|---|
| 排盘准确率 | 100%（黄金样本集全通过） | CI 快照测试 |
| 首屏到出盘时长 | < 800ms（不含动画） | 前端埋点 |
| 解读首 token 延迟 | < 3s（境内模型） | 后端指标 |
| 解读完整率 | > 95%（不中断、不空返回） | 失败日志统计 |
| 游客 → 注册转化 | > 12% | 漏斗埋点 |
| 单次解读成本 | < ¥0.05（默认模型档位） | usage_records 汇总 |
| 开源冷启动 | 首月 500 star 视为达标 | GitHub |

## 7. 竞品参照

| 对象 | 优势 | 短板 | 我们的差异 |
|---|---|---|---|
| 天机六爻（TapTap） | 交互轻、上手快、有游戏感 | 仅六爻、移动端盘面小、AI 黑盒 | 六术并列、桌面级盘面、模型可换、开源 |
| 传统排盘软件 | 规则全、专业 | 界面陈旧、无解释、闭源收费 | 现代交互 + AI 解说 + 免费开源 |
| 各类 AI 算命小程序 | 话术顺滑 | 排盘多为假算或规则缺失，结论无依据 | 真引擎排盘 + 结论可溯源 |
