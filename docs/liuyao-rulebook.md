# 六爻通用取用神规则（v0）

先解决最容易让模型跑偏的一步：**用神是谁**。本表由规则引擎执行，模型不得自行改取；表按《增删卜易》取用神通例整理，具体条文继续逐条校勘，未校勘前不冒充“原书原文”。

## 为什么先做这一层

六爻断卦的准确度首先取决于**取用神是否稳定**。同样一张盘，取错用神，后面的旺衰、生克、应期都会跟着错。把取用神做成确定性规则后：

- 同一问题、同一性别、同一规则版本，主用神应一致；
- 用神不上卦时，规则显式标「用神不现」；若在伏神中出现，标「用神伏藏」，不把伏神当成明现；
- 模型只能解释规则结果，不能临时换用神；
- `AuditReading` 可以拦住“用神为 X”与规则不一致的输出；
- 后续旺衰、生克、应期都能以同一 `rule_id` 往下接。

## 尚未完成

- 旺衰的分项权重（月建、日辰、动爻、变爻、空破墓绝）还没有完整规则化；
- 动爻生克冲合、三合局、暗动、入墓、进退神尚未覆盖；
- 应期的“出空、填实、冲开、值日”还没有独立规则；
- 本表尚未逐条核对原书条文与不同流派异文。

当前版本只声称：**用神取法可复现、可校验、可回测**，不声称已经达到完整六爻断卦的最终准确度。
