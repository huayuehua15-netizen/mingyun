## 1. 历法层（三术共用）

### 1.1 输入归一化

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| local_datetime | string | 是 | 用户输入的本地时刻，`YYYY-MM-DD HH:mm[:ss]` |
| timezone | string | 是 | IANA 时区名，如 `Asia/Shanghai` |
| longitude | number | 否 | 东经为正，用于真太阳时；缺省按时区中央经线 |
| use_true_solar_time | bool | 否 | 默认 true。关闭时直接用标准时 |
| day_boundary | enum | 否 | `zi_chu`（23:00 换日，默认）/ `zi_zheng`（00:00 换日） |

### 1.2 真太阳时

真太阳时 = 标准时 + 经度修正 + 均时差。

- 经度修正：`(longitude - 时区中央经线) × 4 分钟`。东八区中央经线 120°E，东经 113°（广州）约为 −28 分钟。
- 均时差（Equation of Time）：由 sxtwl 提供的太阳视黄经与平黄经差换算，全年在 −14 分 ~ +16 分之间波动。

**关键约束**：真太阳时必须在**判定时辰、判定日界之前**完成换算。否则会出现"23:40 出生、经度修正后落在子时初"这类边界错判。这一步是历法层最容易出错的地方，单测必须覆盖。

### 1.3 干支与节气

| 项 | 规则 |
|---|---|
| 年柱 | 以**立春**交节时刻换年，不是元旦，不是春节 |
| 月柱 | 以**节气**换月（立春→寅月，惊蛰→卯月，以此类推），不是农历月 |
| 日柱 | 以日界规则换日，默认子初（23:00）换日 |
| 时柱 | 两小时一辰，子时 23:00–00:59；时干由日干起（五鼠遁） |
| 节气 | 二十四节气精确到秒，取 sxtwl 结果 |

五鼠遁（时干起法）：甲己日起甲子时，乙庚日起丙子时，丙辛日起戊子时，丁壬日起庚子时，戊癸日起壬子时。

**双引擎校验**：sxtwl 与 lunar_python 对同一年（1900–2100）逐日求干支、逐节气求时刻，差异数量必须为 0。CI 每次跑抽样 200 日，季度全量跑。

### 1.4 旬空与月建

旬空按日干支所属旬首：

| 旬 | 空亡 |
|---|---|
| 甲子旬（甲子–癸酉） | 戌、亥 |
| 甲戌旬（甲戌–癸未） | 申、酉 |
| 甲申旬（甲申–癸巳） | 午、未 |
| 甲午旬（甲午–癸卯） | 辰、巳 |
| 甲辰旬（甲辰–癸丑） | 寅、卯 |
| 甲寅旬（甲寅–癸亥） | 子、丑 |

月建即月柱地支（如寅月月建寅）。月破 = 与月建相冲之支。

## 2. 六爻规格

### 2.1 起卦

**方式一：铜钱摇卦（默认）**

三枚铜钱，摇六次，自下而上成爻（第一次为初爻）。以"背"计数：

| 背数 | 名称 | 记号 | 阴阳 | 动静 | 变后 |
|---|---|---|---|---|---|
| 3 | 老阳（重） | ○ | 阳 | 动 | 变阴 |
| 2 | 少阴（拆） | -- | 阴 | 静 | 不变 |
| 1 | 少阳（单） | — | 阳 | 静 | 不变 |
| 0 | 老阴（交） | × | 阴 | 动 | 变阳 |

**方式二：时间起卦**——以当下真太阳时的年支数、月数、日数、时支数按梅花易数取上下卦与动爻。此方式仅生成卦，不生成"摇卦记录"。

**方式三：手动录入**——用户逐爻选择阴阳动静，引擎只做装卦。

### 2.7 伏神

本卦六亲不全时，取**本宫首卦（八纯卦）**同位爻作为伏神，伏于本卦同位爻（飞神）之下。伏神只取所缺的六亲，不重复已有六亲。

例：乾宫"天风姤"，本卦无"妻财"，则取乾为天第六爻（戌土，妻财）伏于姤卦第六爻之下。

### 2.9 变卦

动爻按 2.1 表翻转阴阳得到变卦。变卦同样装纳甲、定六亲。**变爻只论与本爻的生克关系**（回头生、回头克），不参与对其他爻的生克，也不参与三合局（此为通行做法，流派差异见 2.12）。

变爻的六亲以**本卦卦宫**为"我"来定（开关 `changed_liuqin=ben_gong`）。理由是：整张盘的主语是本卦，变卦只是动爻去向；若改用变卦宫，同一个动爻的六亲会随变卦跳变，断语前后矛盾。需要另一种口径时显式切换开关，盘面与引用都必须重算。

**判定精度要求**：以中气交节时刻为界，精确到分钟。交节当日的课，必须按交节前后分别给出月将。

### 3.2 天地盘

地盘固定：子丑寅卯辰巳午未申酉戌亥，顺时针布十二宫（子在正北，午在正南）。

天盘：把月将放到占时所在的宫位，其余十一支顺时针依次排布。即"月将加时"。

例：月将寅、占时未，则天盘未宫置寅，申宫置卯，依此类推。

### 3.3 四课

| 课 | 取法 |
|---|---|
| 第一课 | 日干寄宫（甲寄寅、乙寄辰、丙寄巳、丁寄未、戊寄巳、己寄未、庚寄申、辛寄戌、壬寄亥、癸寄丑），取该宫天盘上神 |
| 第二课 | 以第一课的上神为地盘，取其上神 |
| 第三课 | 日支宫位，取该宫天盘上神 |
| 第四课 | 以第三课的上神为地盘，取其上神 |

四课上下关系（上神 vs 下神）是判定三传的唯一依据。

### 3.4 三传：九宗门判定

按下表顺序依次判定，命中即止：

| 序 | 宗门 | 触发条件 | 初传取法 | 课体名 |
|---|---|---|---|---|
| 1 | 贼克 | 四课中存在上下相克 | 优先取**下贼上**者；无下贼上则取**上克下**者。唯一候选即定 | 下贼上为"重审"，上克下为"元首" |
| 2 | 比用 | 贼克候选 ≥ 2 | 取与日干**阴阳相同**者（阳日取阳支、阴日取阴支）。仍唯一则定 | 知一课 |
| 3 | 涉害 | 比用后仍 ≥ 2 | 各候选从所临地盘宫**顺数回本家**，计其所历宫位上被克次数，取**最深**者 | 涉害课 |
| 4 | 遥克 | 四课全无克 | 取四课上神克日干者为用（蒿矢）；无则取日干克上神者（弹射） | 蒿矢 / 弹射 |
| 5 | 昴星 | 无克且无遥克 | 阳日取地盘**酉**上神为初传（虎视）；阴日取天盘**酉**下神为初传（冬蛇掩目） | 昴星课 |
| 6 | 别责 | 四课不全（仅三课）且无克 | 阳日取日干**合神之上神**；阴日取日支**三合前神之上神** | 别责课 |
| 7 | 八专 | 干支同宫（甲寅、庚申、丁未、己未、癸丑等）且无克 | 阳日自干上神**顺数三神**；阴日自支上神**逆数三神** | 八专课 |
| 8 | 伏吟 | 占时 = 月将（天地盘重合） | 有克按贼克；无克阳日取干上神（自任）、阴日取支上神（自信） | 伏吟课 |
| 9 | 返吟 | 占时与月将相冲（天地盘全冲） | 有克按贼克；无克取**驿马**为初传 | 返吟课（无依） |

**涉害的深浅判定**（第 3 序）：候选爻所临地盘宫位，若为孟（寅申巳亥）则浅、仲（子午卯酉）次之、季（辰戌丑未）最深的一方为"受克深"。传统口诀"孟浅仲深季更深"，实现时按"从临宫顺数至本家所经宫位，遇地盘克天盘者计数"，计数多者为深。此步流派差异最大，见 3.9。

中传、末传的取法按各宗门传统法度固定，实现时以《大六壬大全》相关章节为准，并在代码注释中标注出处条目。

### 3.5 十二天将

**贵人起法**（天乙贵人）：

| 日干 | 昼贵 | 夜贵 |
|---|---|---|
| 甲、戊、庚 | 丑 | 未 |
| 乙、己 | 子 | 申 |
| 丙、丁 | 亥 | 酉 |
| 壬、癸 | 卯 | 巳 |

昼夜划分：卯至申时为昼（约 05:00–17:00），酉至寅时为夜。落在时辰边界时以真太阳时判定。

## 4. 紫微斗数规格

### 4.1 输入

早子时（00:00–00:59）归当日，晚子时（23:00–23:59）归次日，与 1.3 日界规则一致。

### 4.2 定命宫、身宫

- **命宫**：寅宫起正月，顺数至生月，得月宫；再自月宫起子时，**逆数**至生时，所止之宫为命宫。
- **身宫**：自月宫起子时，**顺数**至生时，所止之宫为身宫。

### 4.4 安紫微星

设生日为 `d`，局数为 `j`：

1. 求最小非负整数 `k`，使 `d + k` 能被 `j` 整除。
2. 商 `q = (d + k) / j`。
3. 自**寅宫**起，顺数 `q` 宫（寅为第 1 宫），得基准宫。
4. 若 `k = 0`，紫微即落基准宫；若 `k > 0`，自基准宫**逆数** `k` 宫，所止之宫为紫微宫。

**校验样例**（水二局，初一）：`d=1, j=2, k=1, q=1`，基准宫为寅，逆数 1 位 → 丑宫。紫微在丑。

### 4.5 安天府

紫微与天府以寅—申轴镜像：设子宫为 0、丑为 1……亥为 11，则
`天府宫位 = (4 − 紫微宫位) mod 12`。

校验：紫微在子(0) → 天府在辰(4)；紫微在寅(2) → 天府在寅(2)；紫微在亥(11) → 天府在巳(5)。

### 4.9 大限、流年

## 5. 输出契约（三术统一）

### 5.1 Chart 顶层

| 字段 | 类型 | 说明 |
|---|---|---|
| chart_id | uuid | 服务端生成 |
| method | enum | liuyao / daliuren / ziwei |
| engine_version | string | 如 `liuyao@1.0.0` |
| calendar | object | CalendarContext 全量 |
| input | object | 归一化后的输入（不含敏感明文，见 09） |
| school | object | 本次使用的流派开关 |
| payload | object | 该术专属盘面，结构见各节 |
| facts | array | 扁平事实清单，AI 唯一输入 |
| warnings | array | 边界提示，如"本次跨节气，已按交节后计算" |

### 5.2 facts 的结构

```
{ key, label, value, anchor, weight }
```

- `key`：稳定的机器标识，如 `liuyao.line.3.najia`。
- `label`：中文可读标签，如"三爻纳甲"。
- `value`：已格式化的字符串，如"辰土·父母·青龙·静"。
- `anchor`：指回 payload 的 JSON Pointer，用于前端高亮。
- `weight`：`core` / `normal` / `minor`，决定注入提示词时的取舍（token 预算紧张时先丢 minor）。

**这张表是 AI 质量的地基**。facts 写得好，提示词就短；facts 写不好，再怎么调提示词都是在补锅。

### 5.3 payload 关键字段示例

六爻：`lines[6]`（position / yin_yang / moving / najia_zhi / wuxing / liuqin / liushen / state_flags / is_shi / is_ying）、`changed_lines[6]`、`palace`、`palace_wuxing`、`fushen[]`、`guashen`、`global`（月建/日辰/旬空/月破）。

大六壬：`tianpan[12]`、`sike[4]`、`sanchuan[3]`、`tianjiang[12]`、`liuqin[12]`、`ke_ti`、`shensha[]`、`xun_kong`。

紫微：`palaces[12]`（name / branch / stem_branch / major_stars[] / minor_stars[] / sihua[] / daxian_range）、`ming_gong`、`shen_gong`、`wuxing_ju`、`ziwei_pos`、`tianfu_pos`、`sihua_year`、`da_xian[]`。

### 6.3 黄金样本的维护

### 6.4 已知不确定性声明

- 岁差与古代历法改革（1582 年格里高利历、1929 年民国改历）前的时刻换算不做支持。

- 术数本身存在流派差异，本文只保证"按本文规则实现"的一致性，不保证"与任意软件一致"。
