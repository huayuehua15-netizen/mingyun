# 09 · 合规与风险

这一章不是可选项。术数类产品在中国大陆属于**监管敏感区**：它既不违法，也从未被明确鼓励，处在"内容合规做得不好就下架、做得好可以长期存在"的灰色带。开源项目还要多一层——代码本身没有地域，但部署者有。

以下为风险提示与工程侧建议，不构成法律意见。正式对外运营前请咨询专业律师。

## 1. 定性：说清楚自己是什么

产品对外一律使用这组表述，全文统一，不得混用：

- **"传统术数文化研究与娱乐工具"**
- **"AI 辅助的盘面解读，不构成任何决策建议"**

禁止使用的表述：

| 禁用 | 原因 |
|---|---|
| "算命""预测未来""知天命" | 直接踩封建迷信定性 |
| "大师""开光""化解""改运""消灾" | 涉迷信服务与诱导付费 |
| "精准预测""百分百准确""最准" | 违反广告法绝对化用语 |
| "AI 命理师""在线真人算命" | 混淆 AI 与真人服务 |

## 2. 四条硬性合规动作

### 2.1 免责声明（必须、不可关闭）

三个位置强制展示，且不能藏在折叠区：

1. 首页底部固定条。
2. 每次解读结果末尾（服务端拼接，不交给模型生成）。
3. 分享页图片底部。

文案要点必须包含：本内容由 AI 基于传统术数规则生成，仅供文化研究与娱乐参考；不构成医疗、投资、法律、婚姻、职业等任何专业建议；涉及上述事项请咨询持证专业人士；用户应对自身决策负责。

### 2.2 禁止事项（写进提示词、写进输出校验、写进用户协议）

- 不做疾病诊断、不推荐停药换药、不解读检查报告。
- 不给具体投资标的、不给买卖点位、不预测股价房价。
- 不出具法律意见、不判断诉讼胜负。
- 不替用户决定婚否、离否、堕胎与否。
- 不针对具体在世第三人做负面论断（"你同事要害你"这类）。
- 不承诺任何结果，不提供"化解/改运"服务。
- 不诱导付费、不以恐吓促成下单（"不化解会有大灾"是典型违规话术）。

### 2.3 AI 生成内容标识

依据《人工智能生成合成内容标识办法》（2025 年 9 月 1 日施行）：

- 文本解读在开头或结尾显式标注"本内容由 AI 生成"。
- 分享图在图片内嵌可见标识（角标文字），不依赖元数据。
- 导出文件（JSON / 图片）附带生成标识字段。
- 若未来接入深度合成（如 AI 语音讲解），需额外满足显式 + 隐式双标识。

### 2.4 生成式 AI 服务备案

若以**公开网站形式向境内公众提供服务**，按《生成式人工智能服务管理暂行办法》需履行备案义务（含算法备案与安全评估）。这条对开源项目的影响是：

- **代码开源本身不构成"提供服务"**，无需备案。
- **谁部署、谁对外运营，谁承担备案责任**。README 必须写这一句，且要显眼。
- 若只是个人自用、局域网、内网，不涉及。

## 3. 个人信息

### 3.1 我们收集什么

| 数据 | 必要性 | 敏感度 |
|---|---|---|
| 出生日期 + 时辰 | 排盘必需 | 高（与地点组合可唯一识别） |
| 出生地经度（用于真太阳时） | 可选，可只填城市 | 中（精确经纬度接近行踪信息） |
| 提问内容 | 必需 | 高（可能含健康、财务、情感等私密信息） |
| 邮箱、IP、UA | 账号与风控 | 中 |

**工程结论**：出生信息与提问内容，一律按敏感个人信息标准处理。

### 3.2 具体要求

| 要求 | 实现 |
|---|---|
| 最小化 | 经度只存到小数点后 2 位（约 1km 精度，足够真太阳时）；不存具体地址 |
| 明确同意 | 注册与首次排盘时勾选，条款单独成段，不与其他条款捆绑 |
| 加密存储 | 出生信息与 provider key 用 AES-GCM 加密，密钥来自环境变量 |
| 可删除 | 一键删除全部盘面与出生信息，30 天内物理清除 |
| 不出境 | 默认模型端点在国内；用户配置境外端点时，界面上明确提示"提问内容将发送至境外服务" |
| 不用于训练 | 明确声明不将用户数据用于模型训练；若未来做，必须单独授权 |
| 日志脱敏 | 日志只记 ID 与长度，禁止打印提问正文与出生时间 |

### 3.3 未成年人

- 用户协议要求 18 岁以上，或 14 岁以上且获监护人同意。
- 不针对未成年人做任何推送与营销。
- 检测到疑似未成年用户时，关闭 AI 解读，仅保留盘面展示。

## 4. 支付与消费者权益（若开启商业化）

- 价格、服务内容、有效期在购买前清晰展示，不做"首月 0.1 元自动续费"这类套路。
- 虚拟服务需明确退款规则；建议提供"未使用额度 7 天内无理由退"。
- 不得以"限量""今日不化解就来不及"等话术促成交易。
- 发票与订单记录保存符合税务要求。

|---|---|---|

| 古籍原文 | 公有领域 | 但**点校本、译注本有版权**，只能录入原文，不得整段抄现代注释 |
| 字体 | SIL OFL（Noto 系列） | 可嵌入与分发，需保留许可文件 |

**风险点**：如果引入"某大师的断卦口诀"作为 RAG 语料，很可能侵权。规则是：**只用 1949 年前出版、且无现代校注的原文**。

## 6. 内容安全

| 风险 | 场景 | 处置 |
|---|---|---|
| 用户提问含政治敏感内容 | 提问框 | 前置敏感词过滤 + 模型侧拒绝 + 记录 |
| 模型输出涉及自杀/自伤 | 用户问"我还能活多久" | 触发危机词，返回心理援助热线，不给命理解读 |
| 模型输出歧视性内容 | 性别、地域、职业 | 输出校验拦截，重生成 |
| 用户上传他人信息 | 替别人算 | 用户协议禁止；技术上不做强校验，但提示"需本人同意" |
| 刷量、爬取 | 公开分享页 | 分享页限流 + 图片水印 + 禁止批量枚举 |
